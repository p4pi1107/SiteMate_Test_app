NBA Historic Roster App
A simple React Native (Expo) application that retrieves and displays a historic NBA team roster using the balldontlie API. Users can browse a team’s past players, tap on a name, and then see player info (position, team, stats, etc.).

Features
Historic Roster: Fetch and display players from a chosen team/season.
Player Search: Click (or tap) on a player’s name to see additional info.
React Native + Expo: Build and test on both Android and iOS simulators (or devices) easily.
